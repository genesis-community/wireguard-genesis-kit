# WireGuard Genesis Kit

Deploys a standalone [WireGuard](https://www.wireguard.com/) VPN
endpoint backed by the
[wireguard BOSH release](https://github.com/cloudfoundry-community/wireguard-boshrelease).

## Quick start

```sh
genesis init -k wireguard
cd wireguard-deployments
genesis new my-env
genesis deploy my-env

genesis do my-env -- add-peer laptop
genesis deploy my-env
genesis do my-env -- generate-wg-config laptop -q
```

## Highlights

- ubuntu-noble stemcells only (kernel WireGuard module required)

- No x509: keys are base64 Curve25519. The blueprint hook ensures the
  server keypair in vault; the credentials DSL is not involved

- Peer lifecycle is a vault registry (`peers/<name>`) plus redeploy —
  changes apply via `wg syncconf` with no tunnel interruption

- NAT/forwarding rules ride on the colocated `iptables` job from the
  cloudfoundry networking release

- OCFP-aware: static IPs come from `net.subnets` reserved-ips key
  `wireguard_ip`; cloud config is generated by the kit

See [MANUAL.md](MANUAL.md) for parameters, addons, and per-IaaS
firewall notes.

## Addons

| Addon | Alias | Purpose |
|-------|-------|---------|
| add-peer | ap | Register a peer (keygen, psk, address allocation) |
| remove-peer | rp | Revoke a peer (moves to revoked/, redeploy applies) |
| list-peers | lp | List registered peers |
| generate-wg-config | gw | Emit a client config (optionally as QR code) |
| smoke | s | Run the colocated smoke-tests errand |
